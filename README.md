# 요매거진 MVP 프로토타입

GitHub Pages에서 바로 볼 수 있는 정적 웹 프로토타입입니다.

## 작업 기준

앞으로의 디자인/QA 수정 작업은 [DESIGN_GUIDELINES.md](./DESIGN_GUIDELINES.md)를 기준으로 진행합니다.

- 홈: 메인 배너, 카테고리, 인기 고민
- 커뮤니티: 카테고리 필터, 최신순/좋아요순, 게시글 목록, 글쓰기
- 마이페이지: 작성 글/댓글, 북마크, 신고/차단 관리, 설정, 외부 연결

## 실행

브라우저에서 `index.html`을 열면 됩니다.
