# 요매거진 MVP 프로토타입

GitHub Pages에서 바로 볼 수 있는 정적 웹 프로토타입입니다.

## 작업 기준

앞으로의 디자인/QA 수정 작업은 [DESIGN_GUIDELINES.md](./DESIGN_GUIDELINES.md)와 [PRODUCT_SPEC.md](./PRODUCT_SPEC.md)를 기준으로 진행합니다. 상세 정책은 `specs/` 아래 도메인별 문서에서 관리합니다.

- 홈: 메인 배너, 요즘 연애 영역, 요매거진 영역, 글쓰기 진입
- 커뮤니티: 카테고리 필터, 최신순 정렬, 무한 스크롤, 게시글과 댓글
- 마이페이지: 계정 정보, 작성 글/댓글, 좋아요한 글, 알림 설정, 약관과 앱 버전
- 공통: 비회원 탐색, 로그인 게이트, 검색, 신고/차단, 알림, 유저 상태, 슈퍼유저, 공유

## 실행

브라우저에서 `index.html`을 열면 됩니다.
