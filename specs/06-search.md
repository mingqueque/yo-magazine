# 검색 정책

- 상태: 게시글 검색 확정, 매거진 검색은 보류 가능
- 최종 갱신: 2026-08-20
- 원문: Notion `검색`

론칭 단계에서는 단순한 검색 구조를 우선하며, 추후 검색 대상을 확장할 수 있다.

## 검색 대상

| 대상 | 포함 여부 | 범위 |
| --- | --- | --- |
| 유저 작성 게시글 | 포함 | 제목과 본문 |
| 매거진 콘텐츠 | 포함 예정 | 제목, 개발 일정에 따라 다음 단계로 보류 가능 |
| 댓글 | 제외 | 검색 결과에 포함하지 않음 |
| 닉네임·사용자 | 제외 | 사용자 검색 미제공 |

## 검색 방식

- 입력한 검색어가 포함된 게시글을 노출한다.
- 게시글에 제목이 있으면 제목과 본문을 모두 검색한다.
- 댓글 내용은 검색하지 않는다.
- 검색어를 구성하는 단어의 2음절 이상 부분 일치 결과까지 포함하는 방향이다.

예를 들어 `복학생 개강 첫날`을 검색하면 `복학생`, `개강`이 포함된 글뿐 아니라 `복학`이 포함된 글도 결과 후보가 된다. 세부 토큰 분리와 매칭 범위는 구현 확인이 필요하다.

검색 경험은 고민과 공감 콘텐츠를 폭넓게 발견할 수 있는 브런치의 탐색 방식을 지향하되, MVP 개발 공수를 우선한다.

## 검색 결과

- 최신순으로 정렬한다.
- 결과 아이템을 누르면 게시글 상세로 이동한다.
- 작성자가 삭제한 콘텐츠는 제외한다.
- 관리자가 숨김 처리한 콘텐츠는 제외한다.

## 검색 UX

`검색 → 검색 결과 → 게시글 상세 → 뒤로가기 → 검색 결과` 흐름에서 다음 상태를 유지해야 한다.

- 입력한 검색어
- 검색 결과
- 사용자가 보던 결과 위치

## 추후 확장 후보

아래 항목은 현재 범위가 아니라 추후 확장 가능성을 고려한 목록이다.

- 매거진 검색
- 카테고리 검색
- 관련도순 정렬
- 필터
- 최근 검색어
- 인기 검색어
- 자동완성
- 추천·연관 검색어

## 디자인과 구현 기준

- 현재 검색 범위가 게시글 중심이라는 점을 결과 UI에 일관되게 반영한다.
- 결과가 없는 상태와 검색 전 상태를 구분한다.
- 상세에서 돌아왔을 때 검색을 다시 실행하거나 처음 위치로 이동시키지 않는다.
- 매거진 검색이 다음 단계로 보류되면 현재 화면에 비활성 탭이나 준비중 결과를 남기지 않는다.
