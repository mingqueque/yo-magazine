# 검색

- 상태: 매거진 검색 보류 가능
- 최종 갱신: 2026-08-21
- 원문: Notion `검색`

현재는 최대한 간단한 데이터 검색 구조로 간다. 추후 검색 대상이 늘어날 수 있다.

## 검색 대상

| 대상 | 포함 여부 | 비고 |
| --- | --- | --- |
| 유저가 작성한 게시글 | 포함 | 제목이 있다면 제목과 본문을 함께 검색 |
| 매거진 콘텐츠 제목 | 포함 | 개발 일정과 공수에 따라 다음 페이즈로 보류 가능 |
| 댓글 | 제외 | |
| 닉네임, 사용자 | 제외 | |

## 검색 결과

- 정렬은 최신순이다.
- 결과 아이템을 선택하면 게시글 상세로 이동한다.
- 작성자가 삭제했거나 관리자가 숨김 조치한 콘텐츠는 결과에서 제외한다.

## 검색 방식

- 검색어가 포함된 게시글 목록을 노출한다. 제목과 글을 모두 포함해 찾는다. 댓글은 결과에서 제외한다.
- 규칙: 검색한 단어 중에 2음절 이상까지 포함한다.
- 추구하는 검색 로직은 `브런치`다.

이야기와 공감이 주 가치인 커뮤니티라 타인이 쓴 글을 조회할 수 있는 폭이 중요하다. 다만 MVP이므로 공수를 과하게 요구하지 않는 선에서 구현 범위를 정한다. 토큰 분리와 부분 일치 범위는 [10-open-decisions.md](./10-open-decisions.md)에서 관리한다.

## 검색 UX 플로우

입력한 검색어와 검색 결과 유지는 필수다.

```
검색 → 검색 결과 → 게시글 상세 → 뒤로가기 → 검색 결과
```

## 추후 확장 고려사항

확정 기능이 아니므로 론칭 범위에 넣지 않는다.

- 매거진 검색
- 카테고리 검색
- 관련도순
- 필터
- 최근검색어
- 인기검색어
- 자동완성
- 추천 및 연관검색어
