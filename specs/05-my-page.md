# 마이페이지

- 상태: 일부 내용 준비중
- 최종 갱신: 2026-08-21
- 원문: Notion `마이페이지`

## 계정 정보

- 로그인 방식을 노출한다. 예) 카카오톡
- 가입한 이메일을 노출한다. 예) abc@gmail.com
- 로그아웃하기
- 탈퇴하기

### 탈퇴

- 탈퇴 이유는 객관식으로 받으며 필수 체크 항목이다.
- 선택 갯수 제한에 대해 원문 본문과 코멘트가 다르다. 본문은 복수 선택 가능, 코멘트는 단수 선택으로 적혀 있어 [10-open-decisions.md](./10-open-decisions.md)에서 관리한다.

탈퇴 이유 보기는 다음과 같다.

- 원하는 콘텐츠가 부족해요
- 커뮤니티가 활발하지 않아요
- 서비스 이용이 불편해요
- 다른 이용자와의 경험이 좋지 않았어요
- 자주 사용하지 않아요
- 개인정보가 걱정돼요

자유 입력도 함께 받는다.

- 글자 수 제한은 500자다.
- 501자 입력 시 토스트 팝업을 노출한다.

탈퇴 시 필수사항에 동의해야 탈퇴할 수 있다. 동의 화면에 노출하는 문구는 다음과 같다.

> 탈퇴 후에도 작성한 글과 댓글은 삭제되지 않고 유지됩니다. 개인정보 등 삭제가 필요한 내용이 포함되어 있다면, 탈퇴 전에 직접 수정하거나 삭제해 주세요.

체크박스 문구는 다음과 같다.

> [필수] 위 내용을 확인했으며, 작성한 콘텐츠가 탈퇴 후에도 유지되는 것에 동의합니다.

탈퇴 이후의 계정과 콘텐츠 처리는 [02-user-status.md](./02-user-status.md)를 따른다.

## 내가 작성한 글

- 최신 작성순으로 나열한다.
- 아이템 클릭 시 해당 페이지로 이동한다.
- 삭제한 글은 노출하지 않는다.
- 아이템 구성은 `리스트 내 게시글 아이템 컴포넌트 기본버전`을 사용한다.

## 내가 작성한 댓글

- 최신 작성순으로 나열한다.
- 아이템 클릭 시 해당 페이지로 이동한다.
- 아이템 구성은 `리스트 내 댓글 아이템 컴포넌트 기본버전`을 사용한다.

## 좋아요한 글

- 좋아요 클릭 최신순으로 나열한다.
- 아이템 클릭 시 해당 페이지로 이동한다.
- 좋아요를 해제한 글은 노출하지 않는다.
- 아이템 구성은 `리스트 내 게시글 아이템 컴포넌트 기본버전`을 사용한다.

## 리스트 아이템 컴포넌트

활동 내역 세 화면이 공유하는 아이템 구성이다.

### 리스트 내 게시글 아이템 컴포넌트 기본버전

`내가 작성한 글`, `좋아요한 글`에서 사용한다.

- 카테고리
- 글 등록 시간
- 게시글 제목
- 본문 미리보기
- 좋아요와 댓글 아이콘, 클릭 개수

삭제되거나 숨김 처리된 게시글은 아예 리스트에 존재하지 않아 노출할 아이템이 없다.

### 리스트 내 댓글 아이템 컴포넌트 기본버전

`내가 작성한 댓글`에서 사용한다.

- 카테고리
- 글 등록 시간
- 게시글 제목
- 내가 쓴 댓글 내용

삭제되거나 숨김 처리된 게시글의 경우 게시글 제목 자리에 `삭제된 글입니다.`를 노출하고 클릭 이벤트를 두지 않는다.

## 알림 설정

- 론칭 버전에 한하여 앱 내 알림 설정은 개발하지 않는다. OS 앱 알림 설정에 따라 알림을 on/off 한다.
- 알림 설정 메뉴를 클릭하면 OS 알림 권한 토글과 연동되는 토글 버튼을 노출한다.
- 푸시 알림 종류와 문구는 [08-notifications.md](./08-notifications.md)에서 관리한다.
