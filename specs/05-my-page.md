# 마이페이지 정책

- 상태: 일부 내용 준비중
- 최종 갱신: 2026-08-20
- 원문: Notion `마이페이지`, `유저 상태`

마이페이지는 회원 전용 화면이며 비회원이 탭을 누르면 로그인 게이트를 노출한다.

## 계정 정보

- 로그인 방식을 노출한다. 예: `카카오톡`
- 가입 이메일을 노출한다.
- `로그아웃하기`를 제공한다.
- `탈퇴하기`를 제공한다.

탈퇴 상태와 완료 화면은 [유저 상태 정책](./02-user-status.md)을 따른다.

## 탈퇴 이유

객관식 사유와 자유 입력을 제공한다.

- 원하는 콘텐츠가 부족해요
- 커뮤니티가 활발하지 않아요
- 서비스 이용이 불편해요
- 다른 이용자와의 경험이 좋지 않았어요
- 자주 사용하지 않아요
- 개인정보가 걱정돼요
- 자유 입력

필수 수집 여부와 선택 방식은 [결정 필요 항목](./10-open-decisions.md)에 남겨 둔다.

## 활동 내역

### 내가 작성한 글

- 최신 작성순으로 나열한다.
- 아이템 클릭 시 해당 게시글로 이동한다.
- 삭제한 글은 노출하지 않는다.

### 내가 작성한 댓글

- 최신 작성순으로 나열한다.
- 아이템 클릭 시 해당 게시글로 이동한다.
- Notion 원문의 `삭제한 글은 노출 X` 적용 범위는 추가 확인이 필요하다.

### 좋아요한 글

- 좋아요를 누른 최신순으로 나열한다.
- 아이템 클릭 시 해당 게시글로 이동한다.
- 좋아요를 해제한 글은 노출하지 않는다.

## 알림 설정

론칭 버전에서는 앱 내 개별 알림 토글을 제공하지 않고 OS 알림 권한을 따른다.

- 메뉴 클릭 시 `휴대폰 설정 > 앱 설정 > 알림 권한을 통해 설정해주세요.` 안내를 노출한다.
- 알림 종류와 발송 규칙은 [알림 정책](./08-notifications.md)을 따른다.

## 정보와 약관

- 커뮤니티 이용규칙: 내용 추후 공유
- 서비스 이용약관: 내용 추후 공유
- 개인정보 처리방침: 내용 추후 공유

## 앱 버전

- 현재 앱 버전 번호를 노출한다.
- 최신 버전이 있으면 앱 업데이트 요청 문구를 노출한다.

## 디자인과 구현 기준

- 계정 정보와 활동 내역을 명확히 구분한다.
- 삭제 또는 좋아요 해제로 제외된 아이템은 빈 자리나 비활성 아이템으로 남기지 않는다.
- OS 설정 안내는 현재 앱 안에서 직접 변경할 수 없다는 점을 분명히 한다.
- 약관 내용이 준비되기 전에는 완료된 문서처럼 오해되는 진입 화면을 만들지 않는다.
