# 알림 정책

- 상태: 검토중
- 최종 갱신: 2026-08-20
- 원문: Notion `알림센터 (단순화가 더 필요한 것 같아 검토중입니다)`, `마이페이지`

이 문서는 현재 검토안이다. 확정 전에는 알림 종류, 문구, 발송 시각을 고정 구현 범위로 간주하지 않는다.

## 공통 동작

- 푸시 알림을 누르면 알림센터로 이동한다.
- 알림센터는 댓글과 좋아요 이벤트를 즉시 쌓는다.
- 좋아요 푸시는 하루 1회 모아서 발송한다.
- 푸시 발송 규칙과 알림센터 적재 규칙은 동일하지 않다.

## 푸시 알림

### 내 글의 새 댓글

- 즉시 발송한다.
- 문구: `내 글에 댓글이 달렸어요 📮`

### 좋아요 모아보기

- 내 글의 좋아요와 내 댓글의 좋아요를 대상으로 한다.
- 하루 1회, 20:00~21:00 사이에 발송한다.
- 직전 24시간 동안 발생한 좋아요를 합쳐 푸시 1개로 발송한다.

| 발생 대상 | 푸시 문구 예시 |
| --- | --- |
| 게시글만 | `오늘 내 글에 좋아요 10개가 달렸어요 💗` |
| 댓글만 | `오늘 내 댓글에 좋아요 10개가 달렸어요 💗` |
| 게시글과 댓글 모두 | `오늘 내 글과 댓글에 좋아요 10개가 달렸어요 💗` |

## 알림센터

### 내 글에 새 댓글

- 반응 종류: `댓글`
- 글 제목
- 카테고리
- 알림 발생 시간
- 댓글 미리보기

### 내 글에 좋아요

- 반응 종류: `좋아요`
- 글 제목
- 카테고리
- 알림 발생 시간
- 추가된 좋아요 수
- 첫 좋아요에도 `새로 달렸어요.` 표현을 사용한다.

### 내 댓글에 좋아요

- 반응 종류: `좋아요`
- 카테고리
- 내가 작성한 댓글
- 알림 발생 시간
- 추가된 좋아요 수
- 첫 좋아요에도 `새로 달렸어요.` 표현을 사용한다.

## 좋아요 알림 이벤트 규칙

동일 사용자가 동일 콘텐츠에 누른 좋아요 알림은 최초 1회만 발생한다.

- 최초 좋아요 이후 취소해도 최초 좋아요 이력을 유지한다.
- 다시 좋아요를 눌러도 추가 알림을 생성하지 않는다.
- 본인 글이나 댓글에 본인이 좋아요를 누른 경우에도 같은 규칙을 적용한다.

## OS 알림 설정

론칭 버전에서는 앱 내 개별 알림 토글을 제공하지 않는다.

- OS 앱 알림 권한으로 전체 알림을 켜거나 끈다.
- 마이페이지 알림 설정 클릭 시 `휴대폰 설정 > 앱 설정 > 알림 권한을 통해 설정해주세요.` 안내를 노출한다.

## 결정 필요

- 스케줄러로 발송한 좋아요 모음 푸시를 알림센터에도 별도 아이템으로 적재할지 확정되지 않았다.
- 정책서 제목 기준으로 알림센터 단순화 검토가 진행 중이다.

## 디자인과 구현 기준

- 푸시와 알림센터가 서로 다른 집계 주기를 사용한다는 점을 상태와 수치 표현에서 혼동하지 않는다.
- 같은 좋아요를 취소·재설정해 중복 알림이 생기지 않아야 한다.
- 검토가 끝나기 전에는 추가 알림 유형이나 세부 설정 토글을 임의로 만들지 않는다.
