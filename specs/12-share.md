# 공유

- 상태: 확정
- 최종 갱신: 2026-08-21
- 원문: Notion `공유`, `마이페이지`

## 공유 진입점

앱 공유는 마이페이지의 `요니버스 앱 공유하기` 메뉴에서만 제공한다.

- 메뉴 로우 맨 우측에 복사 아이콘을 노출한다.
- 클릭하면 OS별 공유하기 옵션 보텀시트를 노출한다.

게시글 상세와 매거진 상세에는 공유 버튼을 두지 않는다. 공유된 링크로 앱 내 특정 페이지까지 이동시킬 수 없어, 상세 화면별 공유를 제공할 실익이 없다고 확정했다.

## 공유 링크 동작

- 론칭 버전에는 OG 설계가 없다.

| 디바이스 상태 | 동작 |
| --- | --- |
| 앱이 설치된 디바이스 | 앱이 열린다 |
| 앱이 설치되지 않은 디바이스 | 해당 OS 앱스토어의 앱 설치 페이지가 열린다 |
