# 공유

- 상태: 버튼 위치 확정 필요
- 최종 갱신: 2026-08-21
- 원문: Notion `공유`

원문에서 새로 추가된 도메인이다.

## 확정된 내용

- 론칭 버전에는 OG 설계가 없다.
- 공유된 메시지의 링크를 클릭했을 때의 이동 액션은 다음과 같다.

| 디바이스 상태 | 동작 |
| --- | --- |
| 앱이 설치된 디바이스 | 앱이 열린다 |
| 앱이 설치되지 않은 디바이스 | 해당 OS 앱스토어의 앱 설치 페이지가 열린다 |

## 공유 버튼 위치

확정 전이다. 원문 코멘트에 남은 논의 내용은 다음과 같다.

- 기존 설계에서는 게시글 상세와 매거진 상세 페이지마다 공유 버튼이 있었다.
- 공유된 링크로 앱 내 특정 도메인이나 페이지로 이동하지 못하고 앱 자체만 열리는 구조라면, 게시글과 매거진 상세의 공유 버튼은 제거하고 마이페이지에 `요니버스 공유하기` 메뉴로만 두는 것이 최적이라는 의견이 있다.
- 원문 이미지와 본문의 링크 유무가 서로 달라 확인이 필요하다는 지적이 함께 있다.

확정 전까지는 기존 구현을 유지하고, 확정 기능처럼 새로 디자인하거나 개발 범위에 넣지 않는다. 진행 상황은 [10-open-decisions.md](./10-open-decisions.md)에서 관리한다.
