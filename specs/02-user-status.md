# 유저 상태 정책

- 상태: 확정
- 최종 갱신: 2026-08-20
- 원문: Notion `유저 상태`, 사용자 전달 내용

## 상태 정의

### 정상

회원가입이 완료되어 서비스 이용 권한이 정상적으로 부여된 상태다.

- 모든 회원 기능을 제한 없이 이용할 수 있다.
- 로그인 후 게시글 작성, 댓글 작성, 좋아요, 신고, 차단 등을 이용할 수 있다.

### 정지

관리자가 어드민에서 수동으로 정지한 상태다.

- 관리자가 유저 상태를 `정지`로 변경하면 즉시 정지 상태로 전환한다.
- 관리자가 유저 상태를 `정상`으로 변경하면 이용 정지를 해제한다.
- 정지 유저의 기존 글과 댓글은 그대로 유지한다.
- 기존 콘텐츠에 `정지처리된 유저입니다.` 같은 상태 문구를 표시하지 않는다.

#### 앱 진입 시

정지 상태의 유저가 앱에 진입하면 아래 안내를 노출한다.

- 문구: `운영 정책 위반으로 서비스 이용이 정지되었습니다. 자세한 내용은 고객센터로 문의해 주세요.`
- 버튼: `확인`

#### 앱 사용 중 정지된 경우

- 다음 서버 API 호출 액션 시점에 정지 상태 전환을 알린다.
- 안내의 `확인` 버튼을 누르면 앱을 종료한다.

#### 정지 유저의 탈퇴

- 고객문의를 통해 요청한다.
- 어드민에서 탈퇴 처리한다.
- 탈퇴 완료 메일은 발송하지 않는다.

### 탈퇴

- 탈퇴 요청 시 즉시 처리한다.
- 처리 즉시 로그인 세션을 종료하고 서비스 이용을 제한한다.
- 기존 로그인 정보로 다시 진입할 수 없다.
- 탈퇴 완료 화면을 노출한다.
- `비회원으로 둘러보기`를 누르면 비회원 상태로 홈에 이동한다.
- 게시글 작성, 댓글 작성, 좋아요 등 회원 기능을 이용할 수 없다.
- 기존 콘텐츠 처리는 개인정보 처리방침을 따른다.
- 기존 글과 댓글에는 `탈퇴한 사용자`를 표시하지 않는다.
- 기존 `익명`, `익명n` 표기와 콘텐츠 노출을 그대로 유지한다.

## 디자인과 구현 기준

- 상태 검사는 회원 기능 실행 전에 우선한다.
- 정지 안내는 우회 동선 없이 고객센터 문의와 확인 액션에 집중한다.
- 정지와 탈퇴 상태는 기존 콘텐츠의 작성자 표시에 영향을 주지 않는다.
- 탈퇴 완료 후 홈에서는 로그인 유저 상태가 남아 있지 않아야 한다.
