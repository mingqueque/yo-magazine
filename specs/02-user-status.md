# 유저 상태

- 상태: 확정
- 최종 갱신: 2026-08-21
- 원문: Notion `유저 상태`

## 정상

- 회원가입이 완료되어 서비스 이용 권한이 정상적으로 부여된 상태다.
- 회원 기능을 제한 없이 이용할 수 있다.
- 게시글 작성, 댓글 작성, 좋아요, 신고, 차단 등 회원 전용 기능을 모두 사용한다.

## 정지

- 정의: 관리자가 어드민에서 수동으로 정지 조치한 유저다.
- 전환: 관리자가 어드민에서 유저 상태를 `정지`로 변경하면 정지 상태가 된다.
- 해제: 관리자가 유저 상태를 `정상`으로 변경하면 이용 정지가 해제된다.

정지 상태에서의 처리는 다음과 같다.

- 정지 유저가 탈퇴를 원하면 고객문의를 통해 접수하고, 어드민에서 탈퇴 처리한다.
- 탈퇴 완료 메일은 발송하지 않는다.
- 정지 유저가 남긴 글과 댓글에 `정지처리된 유저입니다.` 같은 상태 표시를 노출하지 않는다. 콘텐츠는 그대로 둔다.
- 정지 유저는 푸시 알림을 받지 않는다.

### 정지 안내 액션

| 시점 | 처리 |
| --- | --- |
| 앱 진입 시도 시 | 안내 문구와 `확인` 버튼을 노출한다 |
| 앱 사용 중 정지 처리된 경우 | 유저가 서버 API를 호출하는 액션을 한 순간에 정지 상태로 전환되었음을 알린다 |

안내 문구는 다음과 같다.

> 운영 정책 위반으로 서비스 이용이 정지되었습니다. 자세한 내용은 고객센터로 문의해 주세요.

`확인` 버튼을 클릭하면 앱을 종료한다.

## 탈퇴

- 탈퇴 요청 시 즉시 탈퇴 처리한다.
- 탈퇴 처리 즉시 로그인 세션을 종료하고 서비스 이용을 제한한다.
- 기존 로그인 정보로는 앱에 재진입할 수 없다.
- 탈퇴 완료 화면을 노출하고, 그 화면의 `비회원으로 둘러보기`를 누르면 홈으로 이동한다.
- 게시글 작성, 댓글 작성, 좋아요 등 회원 전용 기능을 이용할 수 없다. 시도하면 [로그인 게이트](./01-auth-and-entry.md)가 뜬다.

탈퇴 회원이 남긴 콘텐츠는 다음처럼 다룬다.

- 기존 작성 콘텐츠의 처리 방식은 개인정보 처리방침 정책을 따른다.
- `탈퇴한 사용자`로 별도 표시하지 않는다.
- 기존의 `익명`, `익명n` 표기와 글·댓글 노출을 그대로 유지한다.
