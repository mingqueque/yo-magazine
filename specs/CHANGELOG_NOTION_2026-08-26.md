# Notion 대조 변경점 · 2026-08-26

## 기준 자료

- 사용자가 제공한 Notion Markdown 내보내기 11개
- 첨부된 모바일 화면 캡처 1개
- 기존 `specs/` 문서의 합의된 요니버스 정책

최신 Notion과 기존 스펙이 충돌하면 최신 Notion을 우선했다. 단, Notion에서 취소선 처리한 내용은 phase-out으로 분류하여 개발 스펙에 포함하지 않았다.

## 반영한 변경

| 도메인 | 변경 내용 |
| --- | --- |
| 홈 | `요즘 연애` 랜덤 노출 수를 최대 10개로 명시 |
| 매거진 | 상세 공유 버튼 복원, 이미지 캐러셀·제목·본문 규칙과 관리자 노출 기간/on-off/삭제 정책 추가 |
| 커뮤니티 | 카테고리명을 `결혼`에서 최신 원문의 `결혼 고민`으로 변경 |
| 글 작성 | 작성 카테고리명을 `결혼 고민`으로 변경 |
| 마이페이지 | `요니버스 앱 공유하기` 메뉴와 OS 공유 옵션 시트 동작 복원 |
| 공유 | 게시글·매거진·앱 공유 진입점을 제공하고, 론칭 버전은 복사 및 OS 공유 옵션 시트를 사용하도록 변경 |
| 알림 | 좋아요 스케줄 푸시의 phase-out 우선순위를 명시하고, 같은 원문 안의 잔존 설명과 충돌하지 않도록 정리 |

## 개발에서 제외한 취소선 항목

- `성인` 카테고리와 휴대전화 성인 인증 전체
- 좋아요를 하루 1회 묶어 보내는 스케줄러 푸시
- 게시글·댓글 좋아요 발생 유형별 20:00~21:00 합산 푸시 문구

좋아요 알림은 기존 합의대로 알림센터에 즉시 적재하되 푸시로 발송하지 않는다.

## 유지한 기존 합의

- 차단 댓글 대체 문구는 `차단한 유저입니다.`로 통일
- 론칭 버전의 슈퍼유저 인원 전제와 세부 UI 문구 등 기존 합의 중 최신 Notion과 직접 충돌하지 않는 내용
- 댓글·게시글 입력 UX, 가이드 문구 등 최신 내보내기에 명시되지 않았지만 기존에 확정된 세부 정책

## 남은 확인 사항

- 공유 대상별 실제 URL 및 딥링크 라우팅
- 매거진 제목 검색의 론칭 포함 여부
- 검색의 `2음절 이상 포함` 상세 토큰화 규칙
- 외부 이동 메뉴의 실제 URL
- 약관·개인정보처리방침·커뮤니티 이용규칙 원문
