# 홈

- 상태: 일부 어드민 연계 준비중
- 최종 갱신: 2026-08-21
- 원문: Notion `홈 구성`

홈은 메인 배너, 글 작성 진입, `[요즘 연애]` 섹션, `[요매거진]` 섹션으로 구성한다.

## 메인 배너

- 어드민 연계가 필요하다. 관련 어드민 정책과 연결 링크는 준비중이다.
- 배너 클릭 시 지정된 랜딩으로 이동한다. 랜딩 종류는 세 가지다.
  - 앱 내 특정 페이지
  - 외부 웹사이트
  - 이동 없음
- 배너 안에 페이지 카운터를 배치한다.
- 좌우 스와이프로 다음 배너와 이전 배너로 이동한다.

## 글 작성 진입

- 홈 탭과 커뮤니티 탭의 우측 하단에 플로팅 버튼을 둔다.
- 버튼을 누르면 작성 페이지로 화면을 전환한다.
- 작성 페이지의 입력 규칙은 [11-post-and-comment.md](./11-post-and-comment.md)를 따른다.

## `[요즘 연애]` 섹션

영역명은 `요즘 연애`로 확정되었다.

### 노출 기준

- 카테고리와 관계없이 노출 가능한 전체 게시글을 대상으로 한다.
- 정상적으로 게시 중인 게시글 중 최근 3일 동안 발생한 글 안에서 랜덤으로 선정한다.
- 해당 섹션에서 이전에 노출받지 않은 게시글을 우선 노출한다.
- 게시글 상세 진입 여부와 관계없이, 섹션에 노출된 시점을 기준으로 `노출 이력`에 포함한다.
- 앱에 새로 진입할 때마다 노출 대상을 다시 선정한다.
- 노출 가능한 미노출 게시글이 모두 소진되면 기존에 노출된 게시글을 다시 랜덤 노출할 수 있다.

### 노출 제외 대상

- 삭제된 게시글
- 관리자에 의해 숨김 또는 제재 처리된 게시글
- 사용자가 차단한 작성자의 게시글

## `[요매거진]` 섹션

- 어드민 연계가 필요하다. 관련 어드민 정책과 연결 링크는 준비중이다.
- 편집장이 어드민을 통해 관리한다.
- 게시한 최신순으로 노출한다.
- 매거진 아이템을 클릭하면 매거진 상세 페이지로 이동한다.
- 섹션 하단의 더보기를 클릭하면 매거진 리스트 페이지로 이동한다.

리스트와 상세에 공통으로 적용하는 규칙은 다음과 같다.

- 게시된 날짜를 노출하지 않는다.
- 조회수를 노출하지 않는다. 수집은 한다.
- 숨겨진 매거진은 별도의 삭제 흔적을 남기지 않는다.

### 매거진 상세 페이지

- 인스타그램처럼 이미지를 좌우로 스와이프한다.
- 글은 이미지 하단에 배치한다.
- 이미지 안에 페이지 카운터를 노출한다.
- 공유 버튼을 둔다. 공유 정책은 [12-share.md](./12-share.md)를 따르며, 버튼 위치는 확정 전이다.
- 좋아요 버튼과 클릭 갯수를 노출한다.
