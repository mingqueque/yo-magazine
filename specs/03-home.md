# 홈 정책

- 상태: 일부 어드민 연계 준비중
- 최종 갱신: 2026-08-20
- 원문: Notion `홈 구성`

## 주요 구성

### 메인 배너

어드민 연계가 필요한 영역이다. 관련 어드민 정책은 준비중이다.

- 배너 클릭 시 어드민에서 지정한 랜딩으로 이동한다.
- 랜딩 유형은 앱 내 특정 페이지, 외부 웹사이트, 이동 없음 중 하나다.
- 페이지 카운터를 노출한다.
- 좌우 스와이프로 이전 또는 다음 배너로 이동한다.

### 글 작성 진입

- 홈 우측 하단에 글쓰기 플로팅 버튼을 노출한다.
- 버튼 클릭 후 동작은 [커뮤니티의 글 작성 정책](./04-community.md#글-작성)을 따른다.

### `[-]` 영역

Notion 원문에서 영역명이 `[-]`로 작성되어 있어 실제 노출명은 미확정이다.

- 카테고리와 무관하게 게시글을 무작위로 노출한다.
- 최대 10개를 노출한다.
- 한 면에 5개씩 노출한다.
- 하단에 `2/2 보기` 버튼을 제공한다.
- 버튼을 누르면 나머지 5개를 노출한다.

### 요매거진 영역

편집장이 어드민에서 관리하는 영역이며 관련 어드민 정책은 준비중이다.

- 게시한 최신순으로 노출한다.
- 아이템 클릭 시 매거진 상세 페이지로 이동한다.
- `더보기` 클릭 시 매거진 목록 페이지로 이동한다.
- 게시 날짜는 노출하지 않는다.
- 매거진 상세 페이지에는 공유 버튼을 제공한다.

## 홈과 커뮤니티의 반응 기준

홈의 `지금 뜨는 고민`은 최근 72시간 동안 반응이 빠르게 증가한 게시글을 보여주는 급상승 개념이다. 누적 반응 점수로 정렬하는 커뮤니티의 `반응순`과 구분한다.

## 디자인과 구현 기준

- 배너는 현재 위치와 전체 개수를 알 수 있어야 하며 스와이프 결과가 명확해야 한다.
- 랜딩 유형이 `이동 없음`인 배너는 링크처럼 오해되는 상호작용 피드백을 제공하지 않는다.
- 5개 단위 전환에서 현재 면과 다음 액션을 혼동하지 않도록 한다.
- 홈의 급상승 콘텐츠와 커뮤니티 반응순 콘텐츠가 같은 정렬처럼 보이지 않게 명칭과 문맥을 구분한다.
