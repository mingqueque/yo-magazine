# 글 작성과 본문 구성, 댓글

- 상태: 확정
- 최종 갱신: 2026-08-21
- 원문: Notion `글 작성 / 본문 구성 / 댓글`
- 관련 화면: 홈탭, 커뮤니티탭, 글 상세 페이지

원문에서 별도 도메인으로 분리된 정책이다. 이전에는 커뮤니티 문서에 섞여 있었다.

## 글 작성

- 홈 탭과 커뮤니티 탭의 우측 하단에 플로팅 버튼을 둔다.
- 버튼을 클릭하면 작성 페이지로 화면을 전환한다.

### 작성 페이지 구성

| 항목 | 필수 | 규칙 |
| --- | --- | --- |
| 카테고리 | 필수 | 디폴트는 `썸/소개팅` |
| 제목 | 필수 | 공백 포함 최대 40자. 41자 이상 입력 시 토스트 팝업 |
| 글 | 필수 | 공백 포함 최소 1자, 최대 2000자. 2001자 이상 입력 시 토스트 팝업 |

제목과 글 입력 필드 안에는 현재 글자 수와 최대 글자 수 카운터 UI를 노출하지 않는다.

작성 필드 placeholder는 다음과 같다.

- 제목: `제목을 입력해주세요.`
- 글: `연애이야기를 입력해주세요.`

카테고리 보기는 다음과 같다.

- 썸/소개팅 (디폴트)
- 짝사랑
- 연애중
- 재회
- 이별/권태기/장기연애
- 연애 잡담
- 결혼

그 밖의 규칙은 다음과 같다.

- 사진 첨부는 없다.
- 작성 폼 상단에 익명 작성 안내 문구를 노출한다.
  - `익명으로 글을 작성하고 있어요.`
- 등록 버튼은 제목과 글의 입력 조건을 충족하면 활성화한다.
- 임시저장 기능은 없다.
- 건전한 글 작성 가이드라인 문구를 노출한다.
  - 제목: `서로를 존중하는 글을 작성해 주세요.`
  - 안내: `개인정보, 욕설, 광고, 성범죄 유도 내용은 운영 정책에 따라 숨김 처리될 수 있습니다.`

## 본문 구성

게시글 상세는 다음 요소로 구성한다.

- 카테고리
- 익명 (작성자)
- 작성한 시간 (예: 31분 전)
- 제목
- 본문
- 좋아요 버튼 클릭과 갯수
- 댓글 아이콘과 갯수
- 댓글 리스트
- 댓글 입력 필드
- 수정됨 표시

### 수정됨 표시

수정됨의 범위는 제목, 내용, 카테고리다.
게시글 상세에서는 작성 시간과 붙여 보이지 않도록 제목 아래 별도 줄에 노출한다.

- 단순 띄어쓰기만 바뀌어도 수정사항으로 간주한다.
- 1자라도 추가되거나 삭제되면 수정사항으로 간주한다.

### 케밥 버튼

- 신고하기
- 작성자 차단하기

이전에 차단했던 유저의 글은 나에게 보이지 않는다. 단, 댓글에서는 맥락 파악을 위해 차단한 사용자임이 보인다. 자세한 처리는 [07-report-and-block.md](./07-report-and-block.md)를 따른다.

## 댓글

### 정렬

댓글은 오래된 댓글순으로 나열한다.

### 정상 댓글 구성

- 댓글 작성자: `익명n`
  - 댓글 작성 순서대로 숫자를 부여한다.
  - 슈퍼유저는 이 카운트에서 제외한다. [09-superuser.md](./09-superuser.md) 참고
- 작성 시간 (예: 31분 전)
- 댓글 내용
  - 공백 포함 500자
  - 500자를 모두 채우면 토스트 팝업을 노출한다.
- 댓글 등록 버튼
  - 띄어쓰기를 제외하고 1자 이상 문자를 입력하면 활성화한다.
- 댓글 좋아요 버튼과 갯수
- 케밥 버튼: 신고하기, 작성자 차단하기
- 수정됨 표시: 범위는 게시글과 동일하다.

### 예외 댓글

정상 댓글 기준으로, 아래 상태에 공통으로 적용한다.

- 케밥 버튼을 삭제한다.
- 댓글 좋아요 버튼과 갯수를 삭제한다.
- 댓글 내용은 상태별 대체 문구로 바꾼다.

| 상태 | 대체 문구 |
| --- | --- |
| 댓글 작성자가 삭제한 댓글 | 삭제된 댓글입니다. |
| 관리자가 조치하여 숨김 처리한 댓글 | 숨김 처리된 댓글입니다. |
| 내가 차단한 유저의 댓글 | 차단한 유저입니다. |

차단 댓글 문구는 `차단한 유저입니다.`로 통일한다.
