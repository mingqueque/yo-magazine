# 커뮤니티 정책

- 상태: 확정
- 최종 갱신: 2026-08-20
- 원문: Notion `커뮤니티 탭`, `글 작성 / 본문 구성 / 댓글`, 사용자 전달 내용

## 목록 카테고리

카테고리 선택은 선택 사항이다.

- 기본값: `전체`
- `썸/소개팅`
- `짝사랑`
- `연애중`
- `재회`
- `이별/권태기/장기연애`
- `연애 잡담`
- `결혼 고민`

`성인` 카테고리는 폐지한다.

## 정렬

### 최신순

- 기본 정렬이다.

### 반응순

- 전체 게시글을 누적 반응 점수가 높은 순서로 노출한다.
- 좋아요 1개는 1점이다.
- 댓글 1개는 2점이다.
- 점수가 같으면 최신글을 우선한다.
- 노출 개수 제한은 없다.

홈의 `지금 뜨는 고민`은 최근 72시간의 반응 증가 속도를 보는 급상승 영역이므로 반응순과 다르다.

## 게시글 목록

- 무한 스크롤을 적용한다.
- 목록 하단에 도달하면 다음 게시글을 자동으로 불러온다.
- 데이터를 불러오는 중에는 로딩 아이콘을 노출한다.
- 더 이상 불러올 게시글이 없으면 추가 호출하지 않는다.
- 아이템 클릭 시 게시글 상세 페이지로 이동한다.
- 차단한 작성자의 게시글은 목록에 노출하지 않는다.

## 글 작성

### 진입

- 홈과 커뮤니티 우측 하단에 같은 글쓰기 플로팅 버튼을 노출한다.
- 버튼 클릭 시 작성 페이지로 이동한다.
- 비회원은 로그인 완료 후 작성 페이지로 복귀한다.

### 카테고리

- 필수 항목이다.
- 기본값은 `썸/소개팅`이다.
- 선택지는 목록 카테고리에서 `전체`를 제외한 7개다.

### 제목

- 필수 항목이다.
- 공백 포함 최대 40자다.
- 41자 이상 입력 시 토스트로 알린다.

### 본문

- 필수 항목이다.
- 공백 포함 최소 1자, 최대 2000자다.
- 2001자 이상 입력 시 토스트로 알린다.
- 사진 첨부는 제공하지 않는다.

### 등록과 부가 기능

- 제목과 본문의 입력 조건을 모두 충족하면 등록 버튼을 활성화한다.
- 임시저장은 제공하지 않는다.
- 건전한 글 작성 가이드라인 문구를 노출한다.

## 게시글 상세

다음 요소를 노출한다.

- 카테고리
- `익명` 작성자
- 작성 시간
- 제목과 본문
- 좋아요 버튼과 수
- 댓글 아이콘과 수
- 공유 버튼
- 댓글 목록과 입력 필드
- `수정됨` 표시
- 케밥 버튼

케밥 버튼에는 `신고하기`, `작성자 차단하기`를 제공한다.

제목, 내용, 카테고리 중 하나라도 변경되면 `수정됨`을 표시한다. 단순 띄어쓰기 변경이나 1자 추가·삭제도 수정으로 간주한다.

## 댓글

### 정렬과 작성자 번호

- 오래된 댓글순으로 나열한다.
- 일반 댓글 작성자는 `익명n`으로 표시한다.
- `n`은 해당 게시글에서 처음 댓글을 작성한 순서대로 사용자별로 부여한다.
- 같은 사용자가 여러 댓글을 작성해도 같은 게시글 안에서는 동일한 번호를 유지한다.
- 슈퍼유저는 익명 번호 계산에서 제외하며 [슈퍼유저 정책](./09-superuser.md)에 따라 표시한다.

### 입력과 등록

- 공백 포함 최대 500자다.
- 500자를 모두 채우면 토스트로 알린다.
- 공백을 제외한 문자가 1자 이상이면 등록 버튼을 활성화한다.
- 비회원도 입력할 수 있지만 등록 시 로그인 게이트를 거친다.

### 정상 댓글 구성

- 작성자와 작성 시간
- 댓글 내용
- 좋아요 버튼과 수
- `수정됨` 표시
- 케밥 버튼의 `신고하기`, `작성자 차단하기`

### 예외 댓글

예외 댓글은 케밥 버튼과 좋아요 버튼·수를 제거하고, 실제 내용을 다음 상태 문구로 대체한다.

| 상태 | 대체 문구 |
| --- | --- |
| 댓글 작성자가 삭제 | `삭제된 댓글입니다.` |
| 관리자가 숨김 | `숨김 처리된 댓글입니다.` |
| 내가 차단한 사용자의 댓글 | `차단한 유저입니다.` |

## 디자인과 구현 기준

- 카테고리 필터와 정렬은 서로 독립적으로 변경할 수 있어야 한다.
- 무한 스크롤의 로딩, 마지막 페이지, 빈 결과 상태를 구분한다.
- 글자 수 제한 토스트는 입력을 방해하지 않되 즉시 인지할 수 있어야 한다.
- 예외 댓글은 기존 댓글의 자리를 유지하되 상호작용할 수 없는 상태로 표현한다.
- 글쓰기 플로팅 버튼은 홈과 커뮤니티에서 같은 위치와 형태를 유지한다.
