## 카테고리

- 카테고리는 택일 사항이다.
- 카테고리 종류는 개발사에서 관장한다.

| 순서 | 표기 |
| --- | --- |
| 디폴트 | 전체 |
| 1 | 썸/소개팅 |
| 2 | 짝사랑 |
| 3 | 연애중 |
| 4 | 재회 |
| 5 | 이별/권태기/장기연애 |
| 6 | 연애 잡담 |
| 7 | 결혼 고민 |

`성인` 카테고리는 폐지되었다. 원문에는 폐지된 성인 인증 정책 상세가 접힌 토글로 남아 있으나, 폐지 항목이므로 이 저장소에서는 옮기지 않는다. 필요 시 원문의 `(폐지) 카테고리 > 성인` 토글을 확인한다.

작성 페이지의 카테고리 디폴트는 `전체`가 아니라 `썸/소개팅`이다.

원문에는 커뮤니티 목록에 `썸 / 소개팅`, 작성 페이지에 `썸/소개팅`으로 표기가 갈려 있으나, 사용자가 띄어쓰기 없는 `썸/소개팅`으로 통일하기로 확정했다.

## 고민 글 리스트

- 정렬은 최신순만 제공한다. 론칭 버전에는 최신순만 존재한다.
- 무한 스크롤 방식을 적용한다.
  - 목록 하단에 도달하면 다음 게시글을 자동으로 불러온다.
  - 데이터 로딩 중에는 로딩 아이콘을 노출한다.
  - 더 이상 불러올 게시글이 없으면 추가 호출을 하지 않는다.
- 글 아이템을 클릭하면 게시글 상세 페이지로 이동한다.
