# 인증과 앱 진입 정책

- 상태: 확정
- 최종 갱신: 2026-08-20
- 원문: Notion `로그인 및 앱 내 진입 조건`, 사용자 전달 내용

## 로그인 수단

### Android

- `카카오로 계속하기`를 제공한다.
- 카카오 로그인에서는 이메일 수집이 필수다.

### iOS

- `Apple로 계속하기`를 제공한다.
- `카카오로 계속하기`를 제공한다.
- 카카오 로그인에서는 이메일 수집이 필수다.

슈퍼유저도 같은 회원가입 절차를 이용한다. 권한 부여 방식은 [슈퍼유저 정책](./09-superuser.md)을 따른다.

## 비회원 진입

- 로그인이나 회원가입 없이 앱 내 콘텐츠를 탐색할 수 있다.
- 홈, 목록, 상세 읽기 화면은 비회원에게도 열려 있다.
- 회원 기능이 필요한 페이지나 액션을 실행하는 시점에 로그인 게이트를 노출한다.
- 로그인 완료 후 사용자가 원래 진입하려던 화면과 플로우로 복귀한다.

## 로그인 요구 시점

다음 액션은 비회원 상태에서 실행할 때 로그인을 요구한다.

- 글 작성 버튼 클릭
- 댓글 등록 버튼 클릭
- 좋아요 클릭
- 신고하기 클릭
- 마이페이지 탭 클릭
- 알림센터 클릭

차단은 회원 기능이며, 비회원에게는 차단 액션을 제공하지 않는다.

## 비회원 댓글 작성 플로우

비회원도 댓글 입력 필드에 내용을 작성할 수 있다. 로그인은 등록 시점에 요구한다.

1. 비회원이 댓글을 입력한다.
2. 댓글 등록 버튼을 클릭한다.
3. 로그인 게이트를 노출한다.
4. 로그인 성공 후 기존 댓글 내용을 복원한다.
5. 사용자가 복원된 내용을 확인하고 댓글 등록을 완료한다.

로그인 성공만으로 댓글을 자동 등록하지 않는다.

## 디자인과 구현 기준

- 로그인 게이트에서 로그인 후 원래 맥락으로 돌아간다는 점이 분명해야 한다.
- 댓글 초안은 로그인 전환 과정에서 유실되지 않아야 한다.
- 비회원 탐색 화면에서 로그인 압박을 과도하게 노출하지 않는다.
- 회원 기능 버튼은 비회원에게도 발견 가능하게 두고 실행 시 로그인 게이트로 연결한다.
- 로그인 게이트 복귀 정보에는 대상 화면과 작성 중인 입력 상태가 포함되어야 한다.
