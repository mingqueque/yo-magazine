# 인증과 앱 진입

- 상태: 확정
- 최종 갱신: 2026-08-21
- 원문: Notion `로그인 및 앱 내 진입 조건`

## 로그인 수단

| OS | 제공 수단 | 비고 |
| --- | --- | --- |
| Android | 카카오로 계속하기 | 이메일 수집 필수 |
| iOS | Apple로 계속하기, 카카오로 계속하기 | 이메일 수집 필수 |

슈퍼유저도 일반 유저와 동일한 방식으로 회원가입을 완료한다. 가입 이후 개발사가 지정 계정에 슈퍼유저 권한을 별도로 부여한다. 자세한 내용은 [09-superuser.md](./09-superuser.md)를 따른다.

## 앱 진입 조건

- 로그인이나 회원가입 없이도 앱 내 콘텐츠를 탐색할 수 있다.
- 회원 기능이 필요한 페이지 또는 액션에 진입할 때 로그인을 요구한다.

## 로그인 게이트가 뜨는 시점

| 액션 | 게이트 시점 |
| --- | --- |
| 글 작성 버튼 클릭 | 버튼 클릭 즉시 |
| 댓글 작성 | 입력까지는 비회원도 허용, 등록 버튼 클릭 시 |
| 좋아요 클릭 | 클릭 즉시 |
| 신고하기 클릭 | 클릭 즉시 |
| 마이페이지 탭 클릭 | 탭 클릭 즉시 |
| 알림센터 클릭 | 클릭 즉시 |

## 로그인 후 복귀

- 로그인이 완료되면 기존 진입 플로우로 복귀한다.
- 댓글은 작성 중이던 내용을 유지한 뒤 등록할 수 있어야 한다.

댓글 복귀 플로우는 다음 순서를 그대로 따른다.

1. 댓글 입력
2. 등록 클릭
3. 로그인 게이트
4. 로그인 성공
5. 기존 댓글 내용 복원
6. 유저가 직접 댓글 등록

복원 이후의 등록은 자동으로 처리하지 않고 유저가 다시 등록 버튼을 누른다.
