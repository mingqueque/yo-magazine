# 신고와 차단 정책

- 상태: 확정
- 최종 갱신: 2026-08-20
- 원문: Notion `신고/차단 정책`, `글 작성 / 본문 구성 / 댓글`

## 기본 원칙

- 신고는 서비스 운영 정책을 위반한 콘텐츠를 운영진에게 전달하는 기능이다.
- 차단은 특정 사용자의 콘텐츠를 개인 화면에서 보이지 않거나 상호작용할 수 없게 하는 기능이다.
- 신고와 차단은 목적과 처리 결과를 구분한다.

## 신고하기

### 대상과 진입

- 게시글과 댓글을 신고할 수 있다.
- 게시글 또는 댓글의 케밥 메뉴에서 `신고하기`를 선택한다.
- 별도의 `작성자 신고` 기능은 제공하지 않는다.

### 신고 사유

다이얼로그에서 객관식 사유를 선택한다.

- 욕설 / 비방
- 성적 또는 부적절한 콘텐츠
- 광고 / 홍보 / 도배
- 개인정보 노출
- 기타

`허위 신고 시 불이익을 받을 수 있습니다.` 안내를 노출한다.

### 접수와 처리

- 완료 시 신고 완료 토스트를 노출한다.
- 신고 접수만으로 콘텐츠가 즉시 삭제되거나 신고자에게서 숨겨지지 않는다.
- 운영진이 확인 후 서비스 운영 정책에 따라 조치한다.
- 동일 작성자에게 신고가 반복되면 계정 단위 제재가 가능하다.

어드민에는 다음 정보가 전달되어야 한다.

- 신고 대상 콘텐츠
- 콘텐츠 작성자 정보

운영진은 작성자별 누적 신고 이력을 확인하고 콘텐츠 숨김 또는 사용자 제재를 수행할 수 있어야 한다.

## 작성자 차단하기

### 대상과 진입

- 게시글 작성자와 댓글 작성자를 차단할 수 있다.
- 게시글 또는 댓글의 케밥 메뉴에서 `작성자 차단하기`를 선택한다.
- 차단은 차단한 사용자 개인에게만 적용되며 서비스 전체에서 콘텐츠를 삭제하지 않는다.

### 게시글 처리

- 차단한 작성자의 기존 게시글을 노출하지 않는다.
- 차단 이후 작성되는 신규 게시글도 노출하지 않는다.

### 댓글 처리

차단한 사용자의 실제 댓글 내용은 노출하지 않는다. 게시글 상세에서는 댓글 자리를 유지하고 다음 예외 상태로 대체한다.

- 문구: `차단한 유저입니다.`
- 케밥 버튼 제거
- 좋아요 버튼과 수 제거

이 규칙은 Notion 신고·차단 문서의 `댓글 미노출`과 커뮤니티 문서의 `차단된 댓글 상태 노출`을 함께 만족시키는 표시 기준이다.

### 확장 시 제한

대댓글, 멘션 등 상호작용 기능이 추가되면 차단 사용자와의 상호작용 및 관련 알림을 제한한다.

## 메뉴 구조

게시글과 정상 댓글의 케밥 메뉴는 동일하게 구성한다.

- 신고하기
- 작성자 차단하기

삭제, 관리자 숨김, 차단 사용자 댓글과 같은 예외 댓글에는 케밥 메뉴를 노출하지 않는다.

## 디자인과 구현 기준

- 신고 완료는 운영진 접수 완료이지 제재 완료가 아니라는 점이 드러나야 한다.
- 신고 다이얼로그와 차단 확인 UI는 서로 다른 결과를 명확히 설명해야 한다.
- 차단된 게시글은 목록과 상세 진입 전에 제외한다.
- 차단된 댓글은 실제 내용과 상호작용을 숨기되 댓글 흐름의 자리는 유지한다.
