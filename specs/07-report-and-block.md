# 신고와 차단

- 상태: 확정
- 최종 갱신: 2026-08-21
- 원문: Notion `신고/차단 정책`

신고는 운영진에게 조치를 요청하는 행위다. 차단은 이 사람의 글과 댓글을 더 이상 보고 싶지 않다는 개인 설정이다.

## 기본 원칙

신고와 차단은 목적을 구분하여 운영한다.

- 신고하기: 서비스 운영 정책을 위반한 콘텐츠를 운영진에게 전달하는 기능
- 작성자 차단하기: 특정 사용자의 콘텐츠를 개인 화면에서 보이지 않도록 하는 기능

## 신고하기

### 신고 대상

콘텐츠를 신고한다.

- 게시글
- 댓글 (댓글 상태별 표시를 따른다)

### 신고 방식

- 게시글 또는 댓글의 더보기 메뉴에서 신고하기를 선택한다.
- 신고 시 아래 내용이 함께 운영 어드민에 전달된다.
  - 신고 대상 콘텐츠
  - 해당 콘텐츠 작성자 정보
- 별도의 작성자 신고 기능은 제공하지 않는다. 운영진은 콘텐츠 신고 이력을 기준으로 작성자의 누적 신고 내역을 확인하고, 필요 시 사용자 단위 제재를 진행할 수 있다.

### 신고 액션

신고하기 옵션을 클릭하면 객관식 신고 사유를 노출한다.

- 단수 선택이며 필수 사항이다.
- 자유 입력은 없다.

신고 사유 보기는 다음과 같다.

- 욕설·비방·혐오 표현
- 성적·선정적인 내용
- 광고·홍보·도배
- 개인정보 노출 또는 사칭
- 폭력·위협·불법적인 내용

`허위 신고 시 불이익을 받을 수 있습니다.` 문구를 함께 노출한다.

신고 액션이 완료되면 신고 완료 토스트 팝업을 노출한다.

### 신고 처리

- 신고 접수만으로 콘텐츠가 즉시 삭제되거나 나에게 안 보이게 되지 않는다. 안 보이게 하려면 차단해야 한다.
- 운영진이 신고 콘텐츠를 확인한 후 서비스 운영 정책에 따라 조치한다.
- 동일 작성자에게 신고가 반복적으로 발생하면 계정 단위 제재가 가능하다.

## 작성자 차단하기

### 차단 대상

사람을 차단한다.

- 게시글 작성자
- 댓글 작성자

### 차단 방식

게시글 또는 댓글의 더보기 메뉴에서 작성자 차단하기를 선택한다.

### 차단 시 처리

작성자를 차단하면 차단한 사용자에게 해당 작성자의 콘텐츠를 노출하지 않는다.

- 댓글 내용 부분은 `차단한 사용자의 댓글입니다.`로 노출한다.
- 기존 게시글의 내용을 노출하지 않는다.
- 기존 댓글 내용을 노출하지 않는다.
- 이후 작성되는 게시글 내용을 노출하지 않는다.
- 이후 작성되는 댓글 내용을 노출하지 않는다.

차단은 개인 사용자에게만 적용된다. 해당 작성자의 콘텐츠가 서비스 전체에서 삭제되는 것은 아니다.

게시글 목록에서는 차단한 작성자의 글 자체가 보이지 않는다. 댓글은 맥락 파악을 위해 자리를 유지하고 대체 문구를 노출한다. 대체 문구 표기가 원문 간 다르므로 [10-open-decisions.md](./10-open-decisions.md)에서 관리한다.

## 최종 기능 구조

| 위치 | 제공 기능 |
| --- | --- |
| 게시글 더보기 | 신고하기, 작성자 차단하기 |
| 댓글 더보기 | 신고하기, 작성자 차단하기 |
| 운영 어드민 | 신고 콘텐츠 확인, 작성자별 신고 이력 확인, 콘텐츠 숨김 및 사용자 제재 |
